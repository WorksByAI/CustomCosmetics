# CustomCosmetics

基于 Fabric 的自定义外观模组。支持玩家间同步。

- **SmolPeople**：移植自 Baity 的小人模型，非常可爱于是我就搬过来了。
- **NickTweaks**：自定义昵称、颜色、平滑渐变、流光和动态彩色效果，支持保存配色预设与自定义流光颜色、宽度与间隔。
- **BlockHit**：仿照 1.7 格挡与 Blockhit 动画，可选 Default / Jigsaw 第一人称样式，支持原版及 Hypixel SkyBlock 武器黑/白名单，可选择是否过滤其他玩家的格挡。
- **Animations**：调整手持物品大小、位置、旋转和挥动速度，支持格挡位置、旋转与实时预览。
- **Item Cosmetics**：在本地自定义物品名称与模型，支持已启用资源包中的模型。
- **远程同步**：双方连接远程服务器即可互相看到装饰和格挡。
- **离线模式**：断开远程连接，装饰仅自己可见。
- **更新提示**：每次启动检查 GitHub 最新正式版，有更新时在聊天栏提示。

输入 `/customcosmetics` 打开设置，左下角 GitHub 图标可访问源码仓库。

支持 Minecraft **26.1.x / 26.2 / 26.3**，需要 Java 25、Fabric Loader 0.19.5+ 和对应版本的 Fabric API。
如需共享格挡，还需安装 [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api)。

## English

A Fabric mod for custom cosmetics, with synchronization between players.

- **SmolPeople**: Small player models ported from Baity. I found them so cute that I brought them over.
- **NickTweaks**: Custom nicknames, colors, smooth gradients, shimmer, and animated chroma effects, with saved color presets and customizable shimmer colors, size, and interval.
- **BlockHit**: 1.7-style sword blocking and Blockhit animations, with Default / Jigsaw first-person styles. Supports blacklists and whitelists for vanilla and Hypixel SkyBlock weapons, with optional filtering of other players' blocking.
- **Animations**: Adjust held-item size, position, rotation, and swing speed, with blocking position, rotation, and a live preview.
- **Item Cosmetics**: Local custom item names and models, including models from enabled resource packs.
- **Remote Sync**: Players connected to the remote server can see each other's cosmetics and blocking animations.
- **Offline Mode**: Disconnect from remote services and show cosmetics locally.
- **Update Notifications**: Checks the latest stable GitHub release at startup and shows a chat notice when an update is available.

Use `/customcosmetics` to open the settings. The GitHub icon in the bottom-left corner opens the source repository.

Supports Minecraft **26.1.x / 26.2 / 26.3**. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API for your Minecraft version.
Sharing blocking animations also requires [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api).
