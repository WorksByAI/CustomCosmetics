# CustomCosmetics

基于 Fabric 的自定义外观模组。支持玩家间同步。

- **SmolPeople**：移植自 Baity 的小人模型，非常可爱于是我就搬过来了。
- **Player Size**：独立调整玩家模型的 X、Y、Z 比例，支持玩家间同步。
- **NickTweaks**：自定义昵称、分段渐变、流光和彩色效果，支持本地配色预设。
- **BlockHit**：1.7 风格格挡与 Blockhit，提供 Default / Jigsaw 样式及武器黑/白名单。
- **Animations**：调整手持物品大小、位置、旋转和挥动速度，支持格挡位置、旋转与实时预览。
- **Item Cosmetics**：在本地自定义物品名称与模型，支持已启用资源包中的模型。
- **Cape**：自定义披风，支持图片裁剪与预览；在线共享需审核，本地披风仅自己可见。
- **Accessories**：像素风与精细风原创饰品，支持自由搭配、调色、大小调整与同步。
- **Party**：Hypixel 队友显示、远处标记、追踪线与 IRC For Party Members。
- **远程同步**：双方连接远程服务器即可互相看到装饰和格挡。
- **离线模式**：断开远程连接，装饰仅自己可见。
- **更新提示**：每次启动检查 GitHub 最新正式版，有更新时在聊天栏提示。

输入 `/customcosmetics` 打开设置，左下角 GitHub 图标可访问源码仓库。

支持 Minecraft **26.1.2～26.3**，需要 Java 25、Fabric Loader 0.19.5+ 和对应版本的 Fabric API。
共享格挡或远处队友位置需安装 [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api)。

## English

A Fabric mod for cosmetics and player synchronization.

- **SmolPeople**: Small player models ported from Baity. Too cute to leave out.
- **Player Size**: Synced X/Y/Z player model scaling.
- **NickTweaks**: Custom nicknames, segmented gradients, shimmer and chroma, with saved color presets.
- **BlockHit**: 1.7-style blocking, Default / Jigsaw styles, weapon lists and optional filtering of other players.
- **Animations**: Held-item and blocking transforms, swing speed and preview.
- **Item Cosmetics**: Local custom item names and models, including resource packs.
- **Cape**: Custom capes with cropping, preview and review for sharing.
- **Accessories**: Original Pixel and Detailed cosmetics, with colors, resizing and synchronization.
- **Party**: Teammate highlights, distant markers, tracers and IRC For Party Members.
- **Remote Sync**: Share cosmetics and blocking on the same server.
- **Offline Mode**: Disconnect from remote services and show cosmetics locally.
- **Update Notifications**: Checks GitHub releases at startup and announces updates in chat.

Use `/customcosmetics` for settings; the GitHub icon opens the source.

Supports Minecraft **26.1.2–26.3**. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API for your Minecraft version.
Sharing blocking or distant party positions requires [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api).
