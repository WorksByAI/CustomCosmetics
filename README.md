# CustomCosmetics

当前预览版 v2.0.0-dev.10；最新正式版 v1.8.7。Fabric 客户端外观模组，支持 26.1～26.3，部分功能可在玩家间同步。界面语言可在设置中选择简体中文、English 或跟随游戏。设置中可独立选择语言与字体：Vanilla 跟随游戏字体；Modern 使用内置霞鹜文楷，支持中英文。聊天和外观预览始终跟随游戏字体。

目前模组所有功能（[√] 表示其他安装本模组的玩家可见）：

- **[√] Player Size**：调整人物大小，以及移植自 Baity 的非常可爱的小人模型。
- **[√] Creature Model**：把自己的可见模型切换成原版生物，并同步给安装模组的玩家；只改变画面，不改变碰撞。
- **[√] NickTweaks**：自定义昵称，分段渐变、流光和彩色效果。可屏蔽其他玩家的 Nick。
- **[√] Animation**：还原 1.7 防砍格挡，可添加武器是否格挡的黑／白名单。同时可调整手持物品大小、位置、旋转和挥动速度。
- **[√] Cape**：自定义披风，支持图片裁剪与预览，也可上传原版格式的披风；在线共享需审核，本地披风仅自己可见。
- **[√] Equipments**：原创饰品，支持自由搭配、调色、大小、位置微调。
- **[√] Sharing**：Hypixel 队友显示、远处标记、追踪线与 IRC；可向同一世界公开或指定玩家共享位置（默认关闭）。
- **[√] Skins**：支持导入最高 1024×1024 像素的皮肤，共享仅在 P2P 打洞成功后对其他玩家可见。
- **Item Customization**：自定义物品名称、图标模型、头颅皮肤及穿戴护甲模型与颜色；扫描护符背包后显示收集／升级提示。
- **Damage Splash**：自定义伤害数字的动画、双色渐变／流动彩虹配色、大小与数字格式。
- **Map Editor**：地牢／Kuudra 纯视觉改图、批量方块替换。
- **Waypoints / Shortcuts**：Hypixel Mod API 识别 SkyBlock 岛屿；支持路点、路线、Skyblocker 导入及命令／键鼠快捷方式。
- **Command Tooltips / Snaplook**：查看聊天指令；按住快捷键临时切换视角。
- **Offline Mode**：断开所有远程同步连接，不使用共享功能，也无法看见别人的装饰品。
- 模块：Settings → Module Manager。

用 `/ccos` 或 `/customcosmetics` 打开设置；`/ccos waypoint`、`/ccos shortcuts` 打开工具。需要 Java 25、Fabric Loader 0.19.5+ 和匹配的 Fabric API。
共享功能需安装 [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api)。

## English

Current preview: v2.0.0-dev.10. Latest stable release: v1.8.7. Choose English, Simplified Chinese or follow the game language in Settings. Choose language and font independently: Vanilla follows the game font; Modern uses bundled LXGW WenKai for English and Chinese. Chat and cosmetic previews always follow the game font.

Fabric cosmetics for Minecraft 26.1–26.3, with optional player sync.

Features ([√] visible to other mod users):

- **[√] Player Size**: Adjustable proportions and Baity's miniature player model.
- **[√] Creature Model**: Choose a vanilla mob appearance shared with other mod users; collisions remain unchanged.
- **[√] NickTweaks**: Nicknames, segmented gradients, shimmer and independent blocking.
- **[√] Animation**: 1.7-style blocking, weapon filters, held-item transforms and swing adjustments.
- **[√] Cape**: Import, crop and preview capes. Online sharing requires approval.
- **[√] Equipments**: Accessories with configurable colors, sizes and offsets.
- **[√] Sharing**: Hypixel party member displays, distant markers, tracers and IRC. Optionally share your position publicly within the same world or with selected players (off by default).
- **[√] Skins**: Import skins up to 1024×1024 pixels. Shared skins are visible to other players only after a direct P2P connection is established.
- **Item Customization**: Local item names, icon models, head skins, worn armor models and colors, plus accessory tooltips after scanning the Accessory Bag.
- **Damage Splash**: Damage-number animations, gradients, rainbow colors and formatting.
- **Map Editor**: Visual-only Catacombs/Kuudra map editing and bulk block replacement.
- **Waypoints / Shortcuts**: Hypixel Mod API island markers, routes, Skyblocker import, command aliases and key/mouse shortcuts.
- **Command Tooltips / Snaplook**: Preview chat commands or hold a key to switch perspective.
- **Offline Mode**: Disconnect all remote synchronization connections. Sharing is disabled, and other players' cosmetics are not shown.
- Modules: Settings → Module Manager.

Use `/ccos` or `/customcosmetics` for settings; `/ccos waypoint` and `/ccos shortcuts` open the tools. Requires Java 25, Fabric Loader 0.19.5+ and matching Fabric API.
Sharing modules requires [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api).
