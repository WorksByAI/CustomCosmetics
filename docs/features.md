# 功能列表

输入 `/customcosmetics` 打开设置，也可从 Mod Menu 进入。顶部搜索框支持中英文常用关键词，搜索设置名称与说明，点击结果跳转到对应栏目和位置。设置自动保存，界面支持滚轮和拖动滚动条；关闭后保留页面和滚动位置，闲置 1 分钟后重置。

## Damage Splash

- 参考 Baity 的 FancyDmgSplash，自定义 Hypixel SkyBlock 伤害飘字，仅本地显示，默认关闭。
- Default、Genshin、Arc、Slam、Bounce、Shake、Fall、Spiral 八种动画，设置页实时预览。
- 调整大小、持续时间、渐变起止颜色、暴击符号、粗体和阴影；可将样式应用于普通伤害。
- 数值支持 K/M/B/T/Q 简写，以及逗号、空格、下划线或无分隔符。
- 不修改伤害数值、不删除实体、不增加联网请求；关闭后恢复原版显示。

## Player Size

- 独立调整玩家模型的 X、Y、Z 比例，支持预览和重置。
- 在线同步体型；只改变外观，不改变碰撞箱。
- SmolPeople 子选项：移植自 Baity 的小人模型，可调整手脚摆动速度；与 XYZ 比例共用预览，可组合使用并同步。

## NickTweaks

- 自定义昵称、颜色和粗体；昵称上限 40 字符，包含颜色与格式符号。
- 逐字渐变、平滑渐变、按名字分段设置渐变色。
- Shimmer 鎏金流光：自定义底色、扫光色、高光色、覆盖大小、扫过速度与两次扫光的间隔。
- Chroma 动态彩色：调节亮度、色彩浓度、范围与速度。
- 取色器、HEX 输入、复制、交换和重置颜色，实时预览。
- 配色预设可保存、更新、应用和删除，包含流光大小与间隔；预设仅保存在本地，应用后的配色按正常周期同步。
- 兼容 Modern UI 自定义字体。

## BlockHit

- 1.7 风格格挡与格挡攻击动画，支持左右手、第一人称和第三人称。
- 第一人称 Default / Jigsaw 两种样式。
- 独立调整格挡位置 XYZ 与旋转 XYZ，实时预览和重置。
- 原版与 SkyBlock 武器黑／白名单，支持按名称或物品 ID 搜索、分类筛选和添加手持物品；SkyBlock 按物品 ID 识别。
- 可选择是否用自己的名单过滤其他玩家的格挡；白名单可允许非剑武器格挡。
- 同一 Hypixel 世界内共享格挡；需要 Hypixel Mod API 和 Automatic Sync。
- 仅修改视觉效果，不增加战斗或物品交互数据包。

## Animations

- 手持物品大小、位置 XYZ、旋转 XYZ。
- 挥动 XYZ 幅度与 Swing Speed；默认速度为 `0`，负值减慢、正值加快。
- 关闭视角晃动、切换物品动画或挥动动画；可仅对 Terminator 关闭挥动。
- Ignore Haste 忽略药水对视觉挥动速度的影响。
- 单项或整组重置。

## Item Customization

- 为带唯一 UUID 的 SkyBlock 物品自定义名称和模型，仅本地可见。
- 从背包或装备选择物品，搜索原版及已启用资源包中的模型。
- 名称支持颜色、格式符号和 HEX 颜色，编辑时预览。
- 可重置单件物品或暂停全部自定义效果；资源包模型不可用时恢复原模型。

## Cape

- 系统文件选择窗口，可导入普通图片并裁剪，或直接导入披风＋鞘翅材质。
- 材质支持 `64×32` 的整数倍，文件不超过 2 MB。
- 图片与人物预览、移除本地披风、显示开关。
- 本地披风仅自己可见，切换在线模式不会自动上传。
- 在线披风需本人身份验证并手动提交审核，每账号 24 小时可提交一次；通过后与其他玩家共享。
- 管理员在游戏内收到待审核提醒，并可打开审核页面。

## Equipments (Beta)

- Pixel 像素风与 Detailed 精细风原创饰品库，各部位可独立搭配。
- 包括翅膀、光环、耳朵、全头饰品、帽子、面饰、头发、颈饰、背饰、尾巴、手臂、鞋、裤装、肩饰、宠物、光效与服装。
- 衣柜中选择款式，自定义主色、点缀色与大小；翅膀可调整扇动速度。
- Pixel → Pets 中的 Mini-Me：使用佩戴者皮肤的小人，以坐姿悬浮在肩膀旁边，支持宽臂、细臂、皮肤外层与大小调整；所有宠物可选择左肩／右肩。沿用正常外观同步，离线时仅自己可见。
- 人物预览支持拖动旋转、滚轮缩放和双击重置视角。
- 可单独启停饰品或清空整套搭配；在线时按正常同步周期共享。

## Sharing

### Party Sharing

- Hypixel Mod API 自动识别组队；也可手动 `/p list` 获取名单。
- 已加载队友可选 None、Outline、Fill、Fill + Outline；调整颜色、透明度和线宽，None 仅显示名字与距离。
- Chams 为已加载的队友及接收到位置共享的玩家提供独立的穿墙显示开关。保留原本的皮肤、护甲、披风、装备、饰品与动画，模型自身仍正确相互遮挡，不改变实体、碰撞箱或实体加载距离；未加载玩家仍使用位置标记。
- 队友超出实体加载范围后显示名字与距离标记；双方需开启位置共享并处于同一 Hypixel 世界。
- 位置上报：P2P／UDP 最快每 200ms 一次，WSS 最快每 500ms 一次；拥塞时可继续放慢到 1000ms。远处标记按实际采样间隔平滑插值，格挡与聊天不受此频率限制。
- Tracers 向队友绘制追踪线，支持独立开关与颜色。
- 名字可按距离缩放或保持固定屏幕尺寸，支持调整大小与最大显示距离。
- Nametag Style：Simple 显示名字与距离；Vanilla 保留原始名牌的等级、颜色与图标，不附加距离。优先读取已加载玩家或本地记分板，超出加载范围后使用 TAB／名牌缓存。兼容 Coop、Players 等 TAB 布局；虚拟 TAB 条目按真实 ID 完整匹配，有歧义或资料缺失时回退缓存或真实 ID。不新增同步字段或身份查询。
- 可隐藏指定近距离内的名字和距离标签，默认 8 格，`0` 关闭；保留原版名牌、透视框和追踪线。
- IRC For Party Members：独立组队聊天，支持自定义前缀；默认反引号，留空可将普通聊天发往该频道，指令保持原样。
- 入队连接结果提示可单独关闭；点击提示可打开 Party 设置。
### Location Sharing

- 可向同一 Hypixel 世界的所有接收者或指定玩家共享自己的位置；发送和接收默认均关闭。指定名单可按昵称或真实账号搜索。
- Location Tracers 为接收的位置绘制追踪线，提供独立开关和颜色；使用已有位置数据，不增加同步频率。

## 屏蔽玩家外观

- NickTweaks、Cape、Accessories 分别提供本地屏蔽名单。
- 按已同步的昵称或真实账号名搜索，同时显示真实账号名；支持添加和移除。
- 可使用 `/customcosmetics block <add|remove> <accessories|nick|cape> <昵称或真实账号名>`，省略玩家参数时打开对应名单。
- 屏蔽昵称后恢复原名；屏蔽披风只隐藏本模组披风，保留原版披风。

## Sync 与离线模式

- 自动同步、30～7200 秒刷新间隔、聊天通知，以及带 30 秒冷却的 Sync Now。
- 普通外观设置按同步周期上传；Sync Now 立即执行。
- 离线模式断开模组远程连接，外观仅自己可见。
- 格挡和位置优先使用可用的 P2P，无法直连时使用 UDP 中继，UDP 不可用时回退 WSS；聊天仍走可靠连接。
- DEV：禁用 P2P、自定义本地 UDP 端口、实际连接协议与人数，以及代理设置。
- `/customcosmetics dev` 切换同步调试；支持 `on`、`off`、`status`，可复制报告查看延迟、探测与回退原因。
- 每次启动检查 GitHub 正式版更新，有新版本时在聊天栏提示。

## Map Editor

- **独立文件查看器**：[CCMap 工具](https://cc.toryhi.com/map) 可离线读取 `.ccmap`、搜索材质和坐标，并将可编辑 JSON 转回 `.ccmap`；无需安装，文件不上传。

- **独立压缩存储**：配置目录为 `config/customcosmetics/map-editor/`。`settings.json` 仅保存小体积设置；`presets/` 保存手动预设，`rooms/` 保存房间自动存档。`.ccmap` 使用材质字典、连续坐标合并和 gzip 压缩，保留坐标、朝向参照及原始空气标记。首次升级会流式读取旧 `map-editor.json` 与 `map-rooms.json`，成功后把原文件原样移入 `backups/legacy-*/`，迁移失败时原文件保留。重复迁移优先保留已经保存的新文件；不会降低方块数量上限。备份仍占磁盘空间，确认改图正常后可自行另存或删除备份。

- **Force Dungeon**：默认关闭，位于 Dungeon Only 下方。开启后直接按地牢处理，不需要侧边栏、官方地址或 Mod API 先识别成功；编辑、Freecam、方块识别房间、自动保存与恢复共用此设置。也会检查当前视角附近的房间中心，识别旧固定区域之外的已知房间。设置会保存，可用 `/customcosmetics map force [on/off]` 切换。多人游戏的楼层仍从侧边栏读取，无楼层信息时按识别到的房间保存。单人世界开启 Force Dungeon 且没有楼层信息时，默认整张地图按 **F7／M7 Boss** 共用布局编辑和保存，HUD 标注 `offline forced`，无需原版侧边栏或精确房间特征；保留地图原坐标，不自动平移或旋转。关闭 Force Dungeon 后取消此默认判断；若有明确楼层信息则优先使用该楼层。
- 自动识别直接拼接旧式侧边栏的队伍前缀／后缀，避免内部行 ID 插入 Catacombs 名称造成漏识别，并忽略不可见的字形控制字符。Force Dungeon 关闭后，正常地牢仍会自动识别并恢复已保存的房间改图。`/customcosmetics map status` 显示自动／强制状态、楼层和房间，并将原始侧边栏诊断写入 `logs/latest.log`。
- 支持 F7 与 M7 自动识别，两者的 Boss 房共用一份改图。旧版分开的 F7／M7 配置会合并，并在迁移到新压缩目录时将原 JSON 保存在 `map-editor/backups/legacy-*/`；重叠坐标优先保留 F7，M7 独有坐标一并保留。FME 原始文件不会改写，导入预览会提示冲突。
- 选块菜单支持箱子、末影箱、告示牌、头颅等特殊方块，以及水和岩浆。虚拟箱子仅渲染，不会创建真实容器或碰撞；已有容器可以改色或隐藏，内容和碰撞会保留。`/customcosmetics map blocks`、`blockgui` 和 `import` 会在聊天框关闭后打开对应界面。

- **Freecam（灵魂出窍）**：Map Editor 内开关，或 `/customcosmetics map freecam [on/off]`。可在原版「控制 → 按键绑定 → CustomCosmetics: Map Editor」绑定快捷键，默认未绑定，避免冲突。WASD 飞行，随视线前进，跳跃上升、潜行下降、疾跑加速；速度可调 1–40 格/秒。人物留在原地，鼠标只转动游离视角；改图取点跟随视角。关闭后回到人物，换世界、断线、死亡或上载具时自动退出。只能查看已经加载的区块。游离视角不发送移动、视角或编辑交互包；连接保活、聊天及服务器传送确认继续正常处理。Freecam 开关每次进入世界均为关闭，不会重启自动开启。

- **纯视觉改图**：只替换原模型的材质与 UV，半砖、楼梯等保持原来的模型形状、碰撞、挖掘目标和交互。真实方块被服务器挖掉后不再绘制；已知的“原本有方块”属性会随房间配置保存，重新加载时不会把已挖掉的位置当作新增方块。原本为空气的新增方块只绘制外观，没有碰撞，也不修改世界数据。玻璃与隐藏方块会在渲染时露出相邻表面，避免裁面造成透视空洞，兼容原版、Indigo 与 Sodium。已删除所有改写客户端方块和碰撞的模式。
- **批量替换材质**：Map Editor → Replace Materials，分别选择原方块和目标材质，再点 Replace。默认仅匹配当前房间已加载的原方块类型（忽略朝向等状态）；不同 ID 的半砖、楼梯需分别选择。可以改为 Selected Region，使用 `/customcosmetics map pos1`、`pos2` 设置范围。整批可一次撤销，并自动保存到已识别房间；临时挖掉和服务器恢复继续沿用原有纯视觉行为。修复大面积密集方块替换时卡死，整批仍可撤销。不再限制活跃编辑或单个房间的方块数量；大房间保存也不受旧版 65536 格总数和 8 MiB 文件限制。扫描分帧进行，不请求服务器加载区块。命令示例：`/customcosmetics map replace minecraft:quartz_block minecraft:dark_oak_planks`；末尾加 `selection` 则只替换框选范围。不在可识别房间时请使用框选；未识别区域可用手动 Preset 保存。这是一次性替换，不会自动处理随后新加载的方块。

- Dungeon Only 根据正在显示的 Catacombs 侧边栏识别地牢，支持队伍颜色专用侧边栏、文字格式码与自定义代理连接地址，不依赖官方域名或 Mod API 握手。未识别到地牢时会提示原因，编辑点击仍留在本地。`/customcosmetics map status` 显示识别、编辑开关和瞄准目标的状态。

- 默认关闭。`/customcosmetics map` 打开设置；默认仅在地牢和本地单人世界允许编辑，可关闭 Dungeon Only。保留原版冒险模式，不改变建造权限。
- **FME 操作**：右键直接在相邻位置放置，左键隐藏原方块或删除自定义方块，中键拾取所见材质。Shift＋右键强制替换已隐藏方块。编辑取点跟随当前相机（含独立 Freecam），忽略被隐藏的外观；编辑点击不发送放置、挖掘或交互包。正常游玩前关闭 Edit Mode。
- **Choose Block / Favorites**：图标网格支持名字／ID 搜索；左键选择（绿色）、右键收藏（青色），Favorites 单独显示收藏。`/customcosmetics map blocks` 或 `blockgui` 打开；原版控制设置可绑定选块菜单和编辑模式快捷键，默认未绑定。选择和收藏保存在 `map-editor/settings.json`，普通设置保存不会重写大预设。
- **房间自动保存**：放置、隐藏、删除、填充和撤销自动更新 `map-editor/rooms/` 中对应房间的 `.ccmap` 文件，每个房间独立保存，只写入有变化的房间。使用 FunnyMap 的房间名称和列特征，按房间中心及朝向保存相对坐标，同一房间自动恢复并旋转。目录之外的新房间使用四方向特征匹配，显示 `Room <特征>`。未完整加载或尚未识别时先保留本次编辑，识别完成后补存，不猜测方向。
- Boss 等房间网格以外的区域按 F/M 楼层保存绝对坐标。Automatically Restore Rooms 可关闭自动恢复；编辑仍会保存。Reset This Room 或 `/customcosmetics map clearroom` 清除当前房间模板。
- **Editor HUD** 显示房间、上次编辑房间、模式、所选方块和操作提示，可单独关闭。`/customcosmetics map guide` 查看指南。
- **Import FME Config**：设置页入口或 `/customcosmetics map import`。选择旧版 `extrasConfig.json`、`floorsConfig.json`、`favBlocks.json` 任一个，会读取同文件夹中的三种配置；也支持粘贴目录或拖入文件。先预览，再导入；默认保留已有房间，Replace Existing Room Layouts 开启后才替换。
- 导入保留房间旋转参照、相对坐标及可转换的旧方块属性，包括彩色羊毛、玻璃和石头变种。旧数字楼层同时适用于普通和大师同层，0 对应 Entrance。未知材质、失效属性、方块实体和液体会列在预览中并跳过。原房间结构无法匹配时不盲目套用。导入前在 `map-editor/backups/fme-imports/` 备份设置及受影响的房间文件，旧 FME 文件始终只读。单个输入文件上限 8 MiB。
- 支持现代方块 ID 和属性，如 `minecraft:gold_block`、`minecraft:oak_stairs[facing=east]`；`minecraft:air` 在 Legit 下只隐藏外观，碰撞仍存在。不再限制活跃编辑、预设或房间库的方块数量；支持 32 次撤销，房间库最多 512 个布局。
- **Preset Manager（预设管理器）**：Map Editor → Preset Manager，或 `/customcosmetics map presets`。列表支持按名称／房间搜索，显示方块数量；选中后可加载、重命名、删除，也可填写名字保存当前房间。覆盖和删除需要在界面再点一次确认；删除的文件保存在 `map-editor/backups/presets/`。已识别房间的新预设只保存本房间，以方块识别到的中心和朝向自动对齐，连楼梯等材质状态也一起旋转；加载保留其他房间的编辑，支持 Undo。F7／M7 Boss 共用固定坐标，不需要手动旋转。未识别区域沿用旧锚点保存；旧预设先尝试四方向方块特征匹配，匹配不到会提示，手动角度只保留在 Advanced。`presets/` 每个预设仍为独立 `.ccmap`，兼容查看器。
- 保留区域工具：`pos1`、`pos2`、`fill`、`undo`、`clear`、`anchor`、`save <name>`、`load <name>`。旧手动预设不丢失。此功能不包含 FunnyMap 小地图，也不加载旧 JAR。

### 饰品位置微调

衣橱每个部位提供 **Adjust Position**，可分别调整 X（向右）、Y（向上）、Z（向后），范围各 ±16 模型像素（1 格），步进 0.25 像素，也可直接填写数字。预览实时变化，支持重置。偏移随外观一起同步，其他使用新版模组的玩家也能看到；旧客户端忽略新增字段。切换款式、颜色、大小或宠物左右肩保留偏移。此调整不改变人物的实际碰撞箱。

## Skins

- 本地 PNG 皮肤导入，支持 Wide（Steve）和 Slim（Alex）；选择皮肤不需要 Minecraft 令牌，也不上传至皮肤站。
- 支持 64×64、128×128、256×256、512×512、1024×1024，以及老式 64×32（转换为现代布局），上限 10 MiB。保持原有像素分辨率，保留外层透明度，基础层保持不透明。
- Skins → Import Local Skin 使用系统文件选择器；也可粘贴路径或拖入 PNG 文件。私有皮肤保存到模组配置目录的 `skins/local.png`，重启后继续生效，可一键移除。
- **Share Skin via P2P 默认关闭**；开启后，仅通过现有 Sharing 已建立的、经过身份验证的双向 P2P 直连发送。接收 P2P 皮肤可单独关闭。此功能不会自动开启位置共享。
- 不经过腾讯云 UDP 中继、WSS、HTTP 服务或其他第三方皮肤站。没有直连时仍显示玩家原有皮肤；直连断开或关闭接收后恢复原皮肤。本人的本地皮肤不受直连状态影响。
- 以 640 字节数据块按需传输，使用现有会话加密和重放保护，缺块重试并核对 SHA-256；单客户端皮肤协议总发送限速 8 Mbps（每秒 1,000,000 字节，包含协议和 UDP/IP 开销；短暂突发最多 64 KiB），与位置同步使用独立额度，不会反复传输同一个已缓存文件。实际传输速度受网络、分块请求和协议开销影响。
- 接收的数据先检查尺寸与格式再解码，只在内存中缓存，最多同时解码两个皮肤、缓存 20 张纹理；远端文件不会写入磁盘或执行。
- 此功能独立实现本地导入与直连分享，不包含 CustomSkinLoader 的皮肤站加载列表。
