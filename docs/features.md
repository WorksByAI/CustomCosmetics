# 功能列表

输入 `/customcosmetics` 打开设置，也可从 Mod Menu 进入。顶部搜索框支持中英文常用关键词，搜索设置名称与说明，点击结果跳转到对应栏目和位置。设置自动保存，界面支持滚轮和拖动滚动条；关闭后保留页面和滚动位置，闲置 1 分钟后重置。

## Damage Splash

- 参考 Baity 的 FancyDmgSplash，自定义 Hypixel SkyBlock 伤害飘字，仅本地显示，默认关闭。
- Default、Genshin、Arc、Slam、Bounce、Shake、Fall、Spiral 八种动画，设置页实时预览。
- 调整大小、持续时间、渐变起止颜色、暴击符号、粗体和阴影；可将样式应用于普通伤害。
- 数值支持 K/M/B/T/Q 简写，以及逗号、空格、下划线或无分隔符。
- 不修改伤害数值、不删除实体、不增加联网请求；关闭后恢复原版显示。

## Player Size

- 独立调整玩家模型的 X、Y、Z 比例，支持预览和重置。
- 在线同步体型；只改变外观，不改变碰撞箱。
- SmolPeople 子选项：移植自 Baity 的小人模型，可调整手脚摆动速度；与 XYZ 比例共用预览，可组合使用并同步。

## NickTweaks

- 自定义昵称、颜色和粗体；昵称上限 40 字符，包含颜色与格式符号。
- 逐字渐变、平滑渐变、按名字分段设置渐变色。
- Shimmer 鎏金流光：自定义底色、扫光色、高光色、覆盖大小、扫过速度与两次扫光的间隔。
- Chroma 动态彩色：调节亮度、色彩浓度、范围与速度。
- 取色器、HEX 输入、复制、交换和重置颜色，实时预览。
- 配色预设可保存、更新、应用和删除，包含流光大小与间隔；预设仅保存在本地，应用后的配色按正常周期同步。
- 兼容 Modern UI 自定义字体。

## BlockHit

- 1.7 风格格挡与格挡攻击动画，支持左右手、第一人称和第三人称。
- 第一人称 Default / Jigsaw 两种样式。
- 独立调整格挡位置 XYZ 与旋转 XYZ，实时预览和重置。
- 原版与 SkyBlock 武器黑／白名单，支持按名称或物品 ID 搜索、分类筛选和添加手持物品；SkyBlock 按物品 ID 识别。
- 可选择是否用自己的名单过滤其他玩家的格挡；白名单可允许非剑武器格挡。
- 同一 Hypixel 世界内共享格挡；需要 Hypixel Mod API 和 Automatic Sync。
- 仅修改视觉效果，不增加战斗或物品交互数据包。

## Animations

- 手持物品大小、位置 XYZ、旋转 XYZ。
- 挥动 XYZ 幅度与 Swing Speed；默认速度为 `0`，负值减慢、正值加快。
- 关闭视角晃动、切换物品动画或挥动动画；可仅对 Terminator 关闭挥动。
- Ignore Haste 忽略药水对视觉挥动速度的影响。
- 单项或整组重置。

## Item Customization

- 为带唯一 UUID 的 SkyBlock 物品自定义名称和模型，仅本地可见。
- 从背包或装备选择物品，搜索原版及已启用资源包中的模型。
- 名称支持颜色、格式符号和 HEX 颜色，编辑时预览。
- 可重置单件物品或暂停全部自定义效果；资源包模型不可用时恢复原模型。

## Cape

- 系统文件选择窗口，可导入普通图片并裁剪，或直接导入披风＋鞘翅材质。
- 材质支持 `64×32` 的整数倍，文件不超过 2 MB。
- 图片与人物预览、移除本地披风、显示开关。
- 本地披风仅自己可见，切换在线模式不会自动上传。
- 在线披风需本人身份验证并手动提交审核，每账号 24 小时可提交一次；通过后与其他玩家共享。
- 管理员在游戏内收到待审核提醒，并可打开审核页面。

## Equipments (Beta)

- Pixel 像素风与 Detailed 精细风原创饰品库，各部位可独立搭配。
- 包括翅膀、光环、耳朵、全头饰品、帽子、面饰、头发、颈饰、背饰、尾巴、手臂、鞋、裤装、肩饰、宠物、光效与服装。
- 衣柜中选择款式，自定义主色、点缀色与大小；翅膀可调整扇动速度。
- Pixel → Pets 中的 Mini-Me：使用佩戴者皮肤的小人，以坐姿悬浮在肩膀旁边，支持宽臂、细臂、皮肤外层与大小调整；所有宠物可选择左肩／右肩。沿用正常外观同步，离线时仅自己可见。
- 人物预览支持拖动旋转、滚轮缩放和双击重置视角。
- 可单独启停饰品或清空整套搭配；在线时按正常同步周期共享。

## Sharing

### Party Sharing

- Hypixel Mod API 自动识别组队；也可手动 `/p list` 获取名单。
- 已加载队友可选 None、Outline、Fill、Fill + Outline；调整颜色、透明度和线宽，None 仅显示名字与距离。
- Chams 为已加载的队友及接收到位置共享的玩家提供独立的穿墙显示开关。保留原本的皮肤、护甲、披风、装备、饰品与动画，模型自身仍正确相互遮挡，不改变实体、碰撞箱或实体加载距离；未加载玩家仍使用位置标记。
- 队友超出实体加载范围后显示名字与距离标记；双方需开启位置共享并处于同一 Hypixel 世界。
- 位置上报：P2P／UDP 最快每 200ms 一次，WSS 最快每 500ms 一次；拥塞时可继续放慢到 1000ms。远处标记按实际采样间隔平滑插值，格挡与聊天不受此频率限制。
- Tracers 向队友绘制追踪线，支持独立开关与颜色。
- 名字可按距离缩放或保持固定屏幕尺寸，支持调整大小与最大显示距离。
- Nametag Style：Simple 显示名字与距离；Vanilla 保留原始名牌的等级、颜色与图标，不附加距离。优先读取已加载玩家或本地记分板，超出加载范围后使用 TAB／名牌缓存。兼容 Coop、Players 等 TAB 布局；虚拟 TAB 条目按真实 ID 完整匹配，有歧义或资料缺失时回退缓存或真实 ID。不新增同步字段或身份查询。
- 可隐藏指定近距离内的名字和距离标签，默认 8 格，`0` 关闭；保留原版名牌、透视框和追踪线。
- IRC For Party Members：独立组队聊天，支持自定义前缀；默认反引号，留空可将普通聊天发往该频道，指令保持原样。
- 入队连接结果提示可单独关闭；点击提示可打开 Party 设置。
### Location Sharing

- 可向同一 Hypixel 世界的所有接收者或指定玩家共享自己的位置；发送和接收默认均关闭。指定名单可按昵称或真实账号搜索。
- Location Tracers 为接收的位置绘制追踪线，提供独立开关和颜色；使用已有位置数据，不增加同步频率。

## 屏蔽玩家外观

- NickTweaks、Cape、Accessories 分别提供本地屏蔽名单。
- 按已同步的昵称或真实账号名搜索，同时显示真实账号名；支持添加和移除。
- 可使用 `/customcosmetics block <add|remove> <accessories|nick|cape> <昵称或真实账号名>`，省略玩家参数时打开对应名单。
- 屏蔽昵称后恢复原名；屏蔽披风只隐藏本模组披风，保留原版披风。

## Sync 与离线模式

- 自动同步、30～7200 秒刷新间隔、聊天通知，以及带 30 秒冷却的 Sync Now。
- 普通外观设置按同步周期上传；Sync Now 立即执行。
- 离线模式断开模组远程连接，外观仅自己可见。
- 格挡和位置优先使用可用的 P2P，无法直连时使用 UDP 中继，UDP 不可用时回退 WSS；聊天仍走可靠连接。
- DEV：禁用 P2P、自定义本地 UDP 端口、实际连接协议与人数，以及代理设置。
- `/customcosmetics dev` 切换同步调试；支持 `on`、`off`、`status`，可复制报告查看延迟、探测与回退原因。
- 每次启动检查 GitHub 正式版更新，有新版本时在聊天栏提示。

## Map Editor

- 独立实现的本地地图编辑功能，不包含 FunnyMap 的小地图，不加载旧 JAR。
- 默认关闭。`/customcosmetics map` 打开配置。默认仅限 Hypixel 地牢和本地单人世界；可关闭 Dungeon Only。
- **Legit**：只替换原模型的材质与 UV，半砖、楼梯等保持原来的模型形状、碰撞、挖掘目标和交互。真实方块被服务器挖掉后不再绘制。原本为空气的新增方块只绘制外观，没有碰撞，也不修改世界数据。
- **Cheating**：替换客户端方块和碰撞，其他玩家与服务器保留原地图。关闭、切回 Legit 或换世界时恢复；恢复使用最近收到的服务端状态。服务器可能纠正移动，不能保证不会触发服务器规则。
- Edit Mode：右键涂改所看的方块；Shift＋右键在相邻空气放置；左键撤销该处编辑；中键吸取原方块材质。编辑开启时拦截对应操作，不向服务器发送这些编辑点击。正常游玩前关闭 Edit Mode。
- Block Material 使用方块 ID，例如 `minecraft:gold_block`。`minecraft:air` 在 Legit 下只隐藏原模型，碰撞仍然存在。支持普通方块；不编辑箱子等方块实体或流体。
- `/customcosmetics map pos1`、`pos2` 标记所看方块，`fill` 填充选区；`undo` 撤销，`clear` 清除当前编辑，最多 8192 处编辑、32 次撤销。
- 预设保存到配置文件夹的 `map-editor.json`。可保存、选择、加载、删除，支持 0/90/180/270 度旋转。默认锚点为地牢的 32 格房间中心；`/customcosmetics map anchor` 改为当前站位。支持 `save <name>`、`load <name>` 指令。
- 自动房间识别仅限 Hypixel 地牢区域，比较保存时房间的 9 根原始方块柱与四种旋转。指纹缺失、区块未加载或不匹配时不自动应用，可手动加载。此识别不提供小地图或地牢解谜提示。
- 新预设格式与旧 FunnyMapExtras 配置不直接兼容。

### 饰品位置微调

衣橱每个部位提供 **Adjust Position**，可分别调整 X（向右）、Y（向上）、Z（向后），范围各 ±16 模型像素（1 格），步进 0.25 像素，也可直接填写数字。预览实时变化，支持重置。偏移随外观一起同步，其他使用新版模组的玩家也能看到；旧客户端忽略新增字段。切换款式、颜色、大小或宠物左右肩保留偏移。此调整不改变人物的实际碰撞箱。

## Skins

- 本地 PNG 皮肤导入，支持 Wide（Steve）和 Slim（Alex）；选择皮肤不需要 Minecraft 令牌，也不上传至皮肤站。
- 支持 64×64、128×128、256×256、512×512、1024×1024，以及老式 64×32（转换为现代布局），上限 2 MiB。保持原有像素分辨率，保留外层透明度，基础层保持不透明。
- Skins → Import Local Skin 使用系统文件选择器；也可粘贴路径或拖入 PNG 文件。私有皮肤保存到模组配置目录的 `skins/local.png`，重启后继续生效，可一键移除。
- **Share Skin via P2P 默认关闭**；开启后，仅通过现有 Sharing 已建立的、经过身份验证的双向 P2P 直连发送。接收 P2P 皮肤可单独关闭。此功能不会自动开启位置共享。
- 不经过腾讯云 UDP 中继、WSS、HTTP 服务或其他第三方皮肤站。没有直连时仍显示玩家原有皮肤；直连断开或关闭接收后恢复原皮肤。本人的本地皮肤不受直连状态影响。
- 以 640 字节数据块按需传输，使用现有会话加密和重放保护，缺块重试并核对 SHA-256；单客户端皮肤协议总发送限速 16 KiB/s（短暂突发最多 4 KiB），不会反复传输同一个已缓存文件。高清大文件需要更久。
- 接收的数据先检查尺寸与格式再解码，只在内存中缓存，最多同时解码两个皮肤、缓存 20 张纹理；远端文件不会写入磁盘或执行。
- 此功能独立实现本地导入与直连分享，不包含 CustomSkinLoader 的皮肤站加载列表。
